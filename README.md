# Week 4 - Course Registration System

A simple console-based course registration system written in Java for the Week 4 programming lab assignment.

## Features
- Create at least 3 courses with a name and classroom capacity
- Register students to a course by course name
- Prevents registration if the course is full
- Prevents the same student ID from registering twice for the same course
- View all courses with capacity, enrolled student count and student names

## Classes
- `Student`: studentID, name
- `Course`: courseName, capacity, enrolledStudents
- `Week4`: main program with menu
